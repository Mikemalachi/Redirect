Settings

Redirect is free, with no account, subscription or analytics service.

How this version works

Configure tasks and distractions in advance. A launch from the dashboard opens a full-screen gate. Choose an alternative, open its resource, complete it and confirm. You earn access to the selected distraction for its configured time.

External apps, links and PDFs may open in another window. Actual app usage and task completion are not verified. This web version cannot enforce blocking across your phone.

Local data

Settings, rewards and activity are stored in this browser. PDFs are stored locally in IndexedDB if supported. Clearing site data removes them.

PDF files and daily launch/usage counters are not included in backups; reattach PDFs after importing.

Install on Android

Host this folder on GitHub Pages and open it in Chrome. Use the browser menu to add it to the home screen or install it, if available. No Android app-blocking permissions are requested by this web version.
